# Security

Do not open a public issue containing credentials, tokens, passwords, private endpoints or signing material.

Before publication, the maintainer should enable GitHub private vulnerability reporting in the repository's Security settings. If that feature is available, use **Security → Report a vulnerability**. A separate private contact is not yet configured: **[MAINTAINER: configure a private security contact or enable private vulnerability reporting]**. Until then, request a private reporting channel without disclosing the sensitive details publicly.

If credentials were exposed in a commit, rotate/revoke them and review history cleanup. Deleting the latest copy is not sufficient. This personal/non-commercial project provides no production SLA or guaranteed response time.
