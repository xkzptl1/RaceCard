# Contributing

Small, focused contributions are welcome for maintainer review. Contributions must be compatible with the repository's PolyForm Noncommercial 1.0.0 license; submit only material you have the right to license on those terms. Submission does not transfer ownership or imply a separate copyright assignment.

- Do not submit credentials, tokens, signing files or private data.
- Do not submit F1/FIA/team/driver artwork, diagrams, photographs or fonts without documented redistribution permission and applicable notices.
- Add provenance for factual metadata. Distinguish recorded facts from estimates and unknown values.
- Keep feature changes separate from rights/packaging changes.
- Include focused tests. Timing, replay and UI/data changes should include real Historical validation where appropriate, without committing provider data dumps or unreviewed screenshots.
- Describe the trigger, resulting behavior, validation and remaining limitations in the pull request.
