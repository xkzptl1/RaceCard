# Public source edition

This edition continues from RaceCard 2.7 (273); it is a publication/rights pass, not a redesign.

Excluded: all bundled team SVGs, the supplied icon (authorship/redistribution evidence not available), all previous screenshots and recordings, FIA/F1 source documents, traced road ribbons and presentation shapes, their associated calibration files, raw source snapshots and private diagnostics. No original driver photograph bytes or fonts are bundled. The existing generic avatar and neutral text team badges remain usable in dark and light appearance.

Retained: original Swift code, dependency pins/notices, scalar factual metadata, source URLs, and analytically authored Mock geometry. Driver image URLs can be fetched and cached at runtime under applicable source conditions. Runtime access is not a grant to redistribute those images. Users may supply their own authorized local metadata/assets using the existing local metadata paths; no team logos are automatically downloaded by this publication pass.

Historical maps use recorded OpenF1 XY points when available. Official diagram layers, their calibrations, and some source-aligned sector/turn labels are unavailable in this edition; safety state and text alerts remain. No unverified geometry is fabricated. A downloaded archive still depends on which ranges have been cached. The private-preview screenshots and binaries are not representative of the exact visual assets bundled here.

Source facts/provenance are not offered as a replacement license for their providers. No original FIA PDF, F1 SVG, or road-polygon tracing is included.
