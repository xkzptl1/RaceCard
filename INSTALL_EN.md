# Install RaceCard from source

1. Use an Apple Silicon Mac with macOS 15 or later and Xcode 26.5 or later. Install Python 3.
2. Clone/download this source repository, then run `./Scripts/build.sh` in its folder. The first build downloads the pinned Swift dependencies.
3. Open `build/Products/RaceCard.app`. You may copy it to Applications for personal use.
4. The offline demo needs no account. Choose Sessions for real Historical data. Live requires your own authorized OpenF1 account.
5. Select Settings → Display → Language to switch English/Japanese.

This public source edition has neutral team monograms, optional runtime driver images, and recorded XY maps without the excluded official presentation layers. Missing images show a generic avatar.
